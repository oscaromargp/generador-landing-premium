# Guía de imágenes — Generador Landing Premium

Esta carpeta es para los assets del **repositorio** (no del output generado).

---

## Archivo a agregar: `banner.png`

El banner es la imagen que aparece en la portada del README en GitHub.

**Dimensiones:** 1280 × 400 px  
**Contenido sugerido:**
- Fondo negro (`#000000`) con efecto de partículas o gradiente púrpura/azul
- Texto: "🚀 Generador de Landing Pages Premium"
- Subtexto: "Dark Luxury · Glassmorphism · Animaciones 3D"
- Iconos de las tecnologías: HTML5, CSS3, JS, Claude AI

**Herramientas gratuitas para crearlo:**
- [Canva](https://canva.com) → Busca "GitHub Banner" en plantillas
- [Figma](https://figma.com) → Diseño desde cero con colores de la marca

## Imágenes del OUTPUT generado

Las imágenes que el skill genera para cada landing page van en la carpeta
`images/` del proyecto del usuario, **no aquí**.

Estructura de esa carpeta:
```
images/
  ├── logo.png            # 512×512px, PNG fondo transparente
  ├── hero_visual.png     # 1200×1200px
  ├── service_1.png       # 800×600px
  ├── service_2.png
  ├── service_3.png
  ├── service_4.png
  ├── service_5.png
  ├── service_6.png
  ├── showcase_1.png      # opcional
  ├── showcase_2.png      # opcional
  └── about_image.png     # opcional
```

Consulta los prompts de generación en el `SKILL.md` (sección PASO 1).

## Herramientas para crear GIFs de demo

Si quieres agregar un GIF al README mostrando una landing generada:

| Herramienta | OS | Link |
|---|---|---|
| ScreenToGif | Windows | [screentogif.com](https://www.screentogif.com/) |
