# 🚀 Generador de Landing Pages Premium (Dark Luxury)

Bienvenido al repositorio oficial del **Skill: Generador de Landing Pages Premium**. Esta herramienta está diseñada para crear sitios web de alta conversión con una estética de lujo oscuro, optimización extrema y funcionalidades avanzadas.

## ✨ Características Principales

- **🎨 Diseño Dark Luxury:** Interfaz sofisticada con efectos de Glassmorphism y Vanilla-tilt 3D.
- **🚀 Performance Extrema:** Carga diferida (Lazy Loading), optimización de imágenes (WebP) y SEO técnico integrado.
- **🔗 Integración n8n:** Conexión nativa de formularios mediante Webhooks para automatización de leads.
- **🛡️ Seguridad Honeypot:** Protección silenciosa contra bots y spam.
- **📱 Responsive & Dinámico:** Adaptable a todos los dispositivos con micro-animaciones premium.
- **⚙️ Accesorios de Conversión:** Botón de WhatsApp, contadores de urgencia, tablas de precios y widget de traducción.

---

## 🛠️ Cómo Usar (Prompt Universal)

Este repositorio documenta el **Prompt Universal** que permite a las IAs generativas construir landing pages completas siguiendo una arquitectura técnica rigurosa.

### Pasos para la Generación:

1. **Interacción Inicial:** La IA debe realizar 3 preguntas clave sobre el negocio, sector y color de acento.
2. **Generación de Activos:** Creación automática de imágenes `logo.png`, `hero_visual.png` y servicios.
3. **Despliegue de Código:** Generación de un `index.html` consolidado con CSS y JS inyectado.
4. **Instalación Legal:** Inclusión de plantillas para Privacidad, Cookies y Términos.

---

## 📋 Requisitos para el Desarrollador

- **Google Fonts:** Utiliza *Plus Jakarta Sans* e *Inter*.
- **Vanilla-tilt.js:** Importado vía CDN para efectos 3D.
- **Webhook URL:** Necesitarás tu propio endpoint de **n8n** para procesar los leads.
